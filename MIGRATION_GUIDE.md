# 🚀 Step-by-Step Repository Migration & Update Guide

Follow these exact steps to push the new update and make sure it successfully downloads on devices that already have the old app installed.

---

## Phase 1: Create the Old Repo Redirect on GitHub
Since GitHub does not redirect raw content URLs (`raw.githubusercontent.com`), we need to create a placeholder repository so old apps can find the update details.

1. Go to your GitHub account and create a **new public repository** named exactly: **`Aura-Hub`**
2. In this new repository, create a new file in the root directory named: **`updater.json`**
3. Paste the following contents into it (do not edit it yet, you will update the signature in Phase 2):
   ```json
   {
     "version": "1.0.6",
     "notes": "Migration update to METH VTC Hub! This fixes the repo link on your device.",
     "pub_date": "2026-06-23T21:40:00Z",
     "platforms": {
       "windows-x86_64": {
         "signature": "YOUR_NEW_SIGNATURE_HERE",
         "url": "https://github.com/Chetan302003/Meth-Hub/releases/download/v1.0.6/Aura.VTC.Hub_1.0.6_x64-setup.exe"
       }
     }
   }
   ```
4. Commit this file to the `main` branch of the `Aura-Hub` repository.

---

## Phase 2: Build & Sign the Migration Update (v1.0.6)

Now, we will compile the new code which has the correct `Meth-Hub` settings, generate the signature, and publish it under `Meth-Hub`.

### Step 1: Set Version to `1.0.6`
Make sure the version is bumped to `1.0.6` in the following files:
* **`package.json`**: `"version": "1.0.6"`
* **`src-tauri/tauri.conf.json`**: `"version": "1.0.6"`

### Step 2: Build the Application
Run the build command in your terminal to generate the executable:
```bash
npm run tauri build
```
This will output the bundle file here:
`src-tauri/target/release/bundle/nsis/METH VTC Hub_1.0.6_x64-setup.exe`

### Step 3: Sign the Executable
Generate the cryptographic signature using your private key (from your `.env` file or `updater.key`):
Run this in PowerShell:
```powershell
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD="1234"
npx tauri signer sign -k (Get-Content .\updater.key -Raw) "./src-tauri/target/release/bundle/nsis/METH VTC Hub_1.0.6_x64-setup.exe"
```
*(Copy the long signature string generated by this command).*

---

## Phase 3: Push to GitHub & Publish

### Step 1: Update `updater.json` in BOTH Repositories
1. Open the **`updater.json`** in your local directory.
2. Update the version to `"1.0.6"`.
3. Paste the signature you copied from Step 3 into the `"signature"` field.
4. Set the `"url"` to:
   `https://github.com/Chetan302003/Meth-Hub/releases/download/v1.0.6/Aura.VTC.Hub_1.0.6_x64-setup.exe`
5. Save the file.
6. **Go to the GitHub page of your new placeholder repository `Aura-Hub`**, edit its `updater.json` online, paste the exact same signature, and commit the file.

### Step 2: Push new code to `Meth-Hub`
Commit and push your local files to your main repository (`Meth-Hub`):
```bash
git add .
git commit -m "chore: migrate updater endpoints to Meth-Hub & bump v1.0.6"
git push origin main
```

### Step 3: Create the Release in `Meth-Hub`
1. Go to your **`Meth-Hub`** repository on GitHub.
2. Click **Releases** -> **Draft a new release**.
3. Set the Tag to **`v1.0.6`** (must match the tag version exactly).
4. Go to your local build folder:
   `src-tauri/target/release/bundle/nsis/`
5. Rename the file `METH VTC Hub_1.0.6_x64-setup.exe` to exactly:
   **`Aura.VTC.Hub_1.0.6_x64-setup.exe`** (so it matches the download URL exactly).
6. Drag and drop `Aura.VTC.Hub_1.0.6_x64-setup.exe` into the release attachments box.
7. Click **Publish release**.

---

### 🎉 Result
* Existing users with older versions will query `Aura-Hub/updater.json`, see the new version `1.0.6`, download `Aura.VTC.Hub_1.0.6_x64-setup.exe` from the `Meth-Hub` release, and install it.
* Once installed, their client will now be running `1.0.6` which points to `Meth-Hub` for all future updates.
